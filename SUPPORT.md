# Getting help

- **How-to questions:** ask in [Q&A](https://github.com/HackersHostel/wp2astro/discussions/categories/q-a).
- **Something is broken:** open a [bug report](https://github.com/HackersHostel/wp2astro/issues/new/choose). Include
  the run log from the dashboard (click **Log**) and `CONVERSION_REPORT.md` if you have it.
- **A model or theme doesn't work well:** tell us which one; layout quality varies a lot between models and themes.
- **An idea:** start in [Ideas](https://github.com/HackersHostel/wp2astro/discussions/categories/ideas).
- **A security problem:** report it privately, as [SECURITY.md](SECURITY.md) describes.

The [README](README.md) and [docs/](docs/) cover setup, every provider, GitHub and sync. WP2Astro is maintained by
volunteers, so answers can take a few days.
